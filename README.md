# Cloud IAM Automation: Okta & Azure Integration

## Overview
This project demonstrates how to integrate Okta Identity and Access Management (IAM) with a Node.js application deployed on Microsoft Azure. It features secure authentication, Single Sign-On (SSO), and automated CI/CD deployment using GitHub Actions and OIDC federated identity.

## Key Features
- **Okta Integration:** SSO, MFA, and user management via Okta
- **Azure Deployment:** Automated deployment to Azure Web App
- **CI/CD:** GitHub Actions workflow with secure OIDC authentication
- **Security Best Practices:** Environment secrets, federated identity, and session management
- **Learning Focus:** IAM, automation, and cloud security for real-world IT systems

## Skills Demonstrated
- Okta (IAM, SSO, MFA)
- Azure (Web App, App Registration, Federated Credentials)
- Node.js (Express, OIDC Middleware)
- GitHub Actions (CI/CD, OIDC)
- Automation & Security

## How It Works.
1. **User Authentication:** Okta handles user login, SSO, and MFA.
2. **App Deployment:** Code is pushed to GitHub, triggering a workflow that builds and deploys the app to Azure.
3. **Federated Identity:** GitHub Actions uses OIDC to securely authenticate to Azure without static secrets.

## Why This Project?
This project was built to deepen my expertise in IAM, Okta, and cloud automation—key skills for modern IT and DevOps roles. It reflects real-world scenarios in enterprise environments.
